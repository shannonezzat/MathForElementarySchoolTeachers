Definition 2.1.3.

  1. Let \(s\) and \(t\) be expressions with \(s=t\text{.}\) For any expression \(F(x)\) with a single placeholder “\(x\)”, write \(F(s)\) for the result of uniformly replacing every free occurrence of the placeholder by \(s\text{,}\) and similarly for \(F(t)\text{.}\) Then
    \begin{equation*} s=t \implies F(s)=F(t). \end{equation*}
    For example, if \(2+3=5\text{,}\) then \((2+3)^2+5=5^2+5\) where \(F(x)=x^2+5\text{.}\)

  2. If \(L=R\) is an equation, and \(c\) is any number (or variable that represents a number) then
    1. \(\displaystyle L+c = R+c\)
      🔗
      🔗
    2. \(\displaystyle L-c = R-c\)
      🔗
      🔗
    3. \(\displaystyle L \times c = R \times c\)
      🔗
      🔗
    4. \(L \div c = R \div c\) as long as \(c \neq 0.\)
      🔗
      🔗
    We call this the property of arithmetic equality.
